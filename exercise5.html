NANOG 98 Kea / Stork Workshop

Exercise 5

Installing, registering, and starting the stork-agent on "kea1" and "kea2". Note that various commands in the following exercise will contain: IP_address_of_your_server which must be replaced with the IP address of your "stork" server.

  1. Add the repository to both "kea1" and "kea2":
⎘ COPY

curl -1sLf 'https://dl.cloudsmith.io/public/isc/stork/setup.deb.sh' | sudo -E bash
  1. Install the stork-agent on both "kea1" and "kea2":
⎘ COPY

apt install isc-stork-agent
  1. Now register the agent from both "kea1" and "kea2" to the stork-server on "stork":
⎘ COPY

sudo -u stork-agent stork-agent register --server-url http://IP_address_of_your_server:4780
  1. Now start the stork-agent on both "kea1" and "kea2":
⎘ COPY

systemctl enable --now isc-stork-agent
  1. Check the status of the stork-agent on both "kea1" and "kea2" to make sure it is running:
⎘ COPY

systemctl status isc-stork-agent

  1. Log in to the Stork UI using the folowing: URL: http://IP_address_of_your_server:4780 Username: admin Password: admin Note that you will be forced to change your password. Please use the same password that was supplied to you to log in to these systems as the new password.

  2. Now that you are logged in, please click the "unauthorized machines" link in the banner near the top complaining about "Unregistered machines". You should see "kea1" and "kea2" listed here. Check the box for each and click "Authorize Selected". This will authorize the stork-agent services on "kea1" and "kea2" that were registered in step 3, allowing them to talk to the stork-server on "stork".

  3. Refresh the page. This would not be strictly necessary but there would be a substantial delay before the UI was updated with new items in the menus if not done.

  4. Click the hamburger menu and choose "DHCP" (DHCP may not be under the hamburger menu depending on width of your web browser window).

  5. Click "Dashboard".

  6. There should be a green checkmark ✅ in "Status" for "kea1" and "kea2".

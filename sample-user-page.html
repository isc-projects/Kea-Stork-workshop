How to arrange your terminal windows and connect

  1. Open one copy of a terminal application per ssh connection (or one tab if you prefer).
    Windows: Launch four copies of the "Terminal" App via the search bar. This App is installed by default in Windows 11. It can be downloaded from the "Microsoft Store" for Windows 10.
    MacOS: Launch four copies of the "Terminal" application by pressing command(⌘)+space and typing: "terminal" and pressing enter. Press command(⌘)+N three times to open three more terminal windows.
    Linux: launch four copies of your favorite terminal emulator.

  2. Size and arrange the windows such that you can easily switch between them. Remember which one is which as you will need to perform specific exercises and steps on specific machines.

  3. Connect to one server VM per terminal window using the ssh commands listed above.

  4. You should get a prompt that contains the name shown above the ssh command when successful.
